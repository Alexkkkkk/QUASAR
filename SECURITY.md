# Security policy

QUASAR is pre-testnet software and has not received a formal third-party
audit. Do not use it with significant funds.

## Reporting a vulnerability

Do not publish exploit details in a public issue. Send a private report to
`security@quasar-ton.dev` with:

- affected contract, file, or deployment flow;
- concise impact assessment;
- reproducible steps or a minimal proof of concept;
- whether the issue is already deployed on testnet or mainnet.

Do not include wallet mnemonics, private keys, API keys, or other secrets in a
report.

## Scope

Reports involving unauthorized transfers, supply or reserve accounting,
permission bypasses, incorrect bounce handling, or deployment misconfiguration
are in scope. Feature requests and documentation corrections belong in the
public issue tracker.
