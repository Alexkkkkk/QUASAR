## 4. Решение, оставленное владельцу

**MIME-источник TEP-64 метаданных.** `.env.example` по умолчанию указывает на
`raw.githubusercontent.com`, который отдаёт `text/plain; charset=utf-8`.
GitHub Pages-артефакт (`https://alexkkkkk.github.io/QUASAR/metadata.json`) уже
отдаёт корректный `application/json`. Смена значения по умолчанию меняет
аргумент `init` → код-хеш → адрес контракта, поэтому это осознанное решение
владельца перед публичным деплоем, а не молчаливая правка. Факт и рекомендация
зафиксированы в `docs/TON_CONFORMANCE_MATRIX.md`.
