# QUASAR — отчёт аудита и синхронизации (2026-10-02)

Полный аудит репозитория, исправление найденных ошибок и синхронизация кода с
[документацией TON](https://docs.ton.org/). Отчёт фиксирует **только**
проверенные факты: что сломано, что исправлено, что осталось внешней операцией.

База: ветка `main`, коммит `1d73379`. Инструменты: `@tact-lang/compiler`
(вывод: **Tact объявлен deprecated**, см. ниже), `@ton/sandbox`, CI-гейты
репозитория.

### Подтверждено корректным (не требует правок)

- **TEP-74**: opcode `transfer 0x0f8a7ea5`, `internal_transfer 0x178d4519`,
  `burn 0x595f07bc`, `burn_notification 0x7bdd97de`, `excesses 0xd53276db` —
  совпадают со [стандартом](https://github.com/ton-blockchain/TEPs/blob/master/text/0074-jettons-standard.md).
- **TEP-64**: контент-ячейка `0x00` (on-chain/semi-chain) и `0x01` (off-chain URI);
  префикс валидируется в `ProposeContent` (`prefix == 0x00 || prefix == 0x01`).
- **TEP-89**: `provide_wallet_address 0x2c76b973` → `take_wallet_address 0xd1735400`,
  `owner_address` — ссылкой (`Cell?`), ответ mode 64, ветка `addr_none` для
  чужого workchain — реализовано и в мастере, и в кошельке.
- **TON Connect manifest**: `url`, `name`, `iconUrl` (180×180 PNG, не SVG) —
  соответствует [требованиям](https://docs.ton.org/v3/guidelines/ton-connect/guidelines/creating-manifest).
  Живая проверка: manifest отдаётся `application/json`, иконка — `image/png`.

## 3. Границы (что НЕ входит в on-chain код)

Согласно [docs.ton.org](https://docs.ton.org/), документация описывает не только
контракты, но и SDK, API/indexer, TON Connect, Pages и toolchain. Эти
обязанности намеренно **не** встраиваются в `QuasarMaster`/`QuasarWallet` и
отслеживаются отдельно (#77). NFT/SBT/vesting в Jetton-контракт не добавлялись.

## 4. Открытые release-gates (внешние операции, не выполняются CI)

- **#62** — независимый аудит и публикация адресов + build hash перед mainnet.
- **#74 / #77** — live TON Connect smoke после Pages и testnet integration smoke.
- **#86** — фактический testnet handoff владения на внешний multisig (runbook
  готов: `docs/MULTISIG_HANDOFF_RUNBOOK.md`).

## 5. Проверки после исправлений

```bash
npm run lint
npm run security:check
npm test
npx tsc --noEmit
npm run abi:verify
npm run abi:dapp
```

Изменения не затрагивают `contracts/*.tact`, поэтому code hash и адреса
контрактов **не меняются**.
