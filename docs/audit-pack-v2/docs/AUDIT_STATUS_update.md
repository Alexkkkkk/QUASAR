| M-4a | Fee-поток и автобайбэк живы в паузу | при паузе глушатся исходящие ноги FeeTransfer (treasury, байбэк); приём и burn работают |

| F-31 | Permissionless execute в таймлоке | переформулировано: «осознанно permissionless» (payload неизменен, allow-list, delete-before-send) — не баг |
| F-32 | Ротация оракула ломалась на stale query | fixed (тест audit_f31_f32) |
| F-33 | Dead config в `get_fee_config` | getter возвращает реальные константы (L-4) |
| F-34 | Безграничный рост priceHistory/anomalyLog | капы 2048/1024 + dropped-счётчики |
| F-36 | Неявный range-check сжигания | явный `require(burnAmount <= totalSupply)` |
| F-38 | Ложный комментарий buyback | кап swapPart остатком резерва + честный комментарий |
| L-1 | Tombstone-байбэка: потеря restore при bounce старой ноги | память двух ног; неизвестный bounce эмитит событие вместо revert |
| L-2 | Коллизия queryId пользователь/пул в bounce кошелька | marker-бит `1 << 63` на пуловых выплатах, маршрутизация по биту |
| L-3 | Residual TON на нулевой адрес | излишек остаётся в кошельке при `addr_none` |
| L-5 | Rewind `lastClaim` при restore наград | restore ставит `lastClaim = now()`, без дорисовки на топ-ап |
| L-6 | Пыль наград (целочисленное начисление) | задокументировано: начисления < 1 nano копятся до порога |
| L-7 | `estimateLpOut` падает при нулевых резервах | zero-guard, возвращает 0 |
| L-8 | Gas-зависимость кошелька | задокументировано в UI (top-up предупреждение) |
