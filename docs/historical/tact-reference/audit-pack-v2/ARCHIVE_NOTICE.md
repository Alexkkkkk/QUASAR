# Archived Tact audit proposal pack

This directory is retained as historical review evidence only. Its `.tact.txt`
contract proposals and `.ts.txt` test drafts are **not active source code**, are
not compiled or run, and must not be copied into the canonical contracts.

The active implementation is under `tolk/contracts/` and is built, checked,
and emulated with the pinned Acton toolchain. Any proposal reused from this
archive must be re-evaluated against the current Tolk implementation, ABI,
state layout, security checks, and tests.
