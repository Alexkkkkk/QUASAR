# [Security][Low] Пакет low-находок L-1, L-2, L-3, L-5, L-7, L-8

Шесть низкоприоритетных находок одним issue, одним PR.

## L-1 — tombstone-байбэка в QuasarDeFi
Bounce `BuybackTon` предыдущей ноги, прилетевший после подмены tombstone,
revert'ил обработчик → потеря восстановления `tonReserve`/`feeAccumulatedTon`.
**Фикс:** память двух последних ног; неизвестный bounce эмитит событие вместо revert.

## L-2 — коллизия queryId в bounce кошелька
Пользовательский трансфер с queryId, совпавшим с seq пуловой выплаты,
обрабатывался бы как пуловый (fee + residual теряются).
**Фикс:** marker-бит `1 << 63` на пуловых выплатах, маршрутизация bounce по биту.

## L-3 — residual TON на нулевой адрес
`TokenTransfer` отправлял residual на `responseDestination` без проверки
`addr_none`. **Фикс:** излишек остаётся в кошельке (газ будущих транзакций).

## L-5 — rewind `lastClaim` при restore
Bounce-восстановление награды стейкинга перематывало `lastClaim` на прошлое,
дорисовывая начисления на топ-апнутую сумму. **Фикс:** restore ставит `now()`.

## L-7 — `estimateLpOut` падает на нулевых резервах
**Фикс:** zero-guard, getter возвращает 0.

## L-8 — gas-зависимость кошелька
Код не меняется: задокументировать в minter-dapp UI (top-up предупреждение
при `myBalance() < 0.075 TON`).

## Критерии приёмки

- [ ] Sandbox-тесты: L-1 (bounce старой ноги восстанавливает), L-2 (коллизия
      невозможна: пользовательский bounce с marker-битом отсутствует в ledger),
      L-3 (residual не уходит на нулевой адрес), L-5 (restore без rewind),
      L-7 (getter на пустом пуле)
