# Учебный Counter на Tolk

Это минимальный учебный проект на Tolk, созданный на основе шаблона Acton CLI **1.2.1**. Он находится отдельно от `tolk/contracts/` и не является частью QUASAR, его ABI, сборки или адресов.

Контракт хранит владельца и счётчик. Только владелец может увеличить, уменьшить или сбросить значение. Уменьшение ниже нуля и увеличение выше `uint32` отклоняются. Тесты проверяют успешные вызовы, отказ в доступе, границы значения и неизвестные сообщения в локальной эмуляции.

## Проверка

Нужен Acton CLI 1.2.1. Из корня репозитория выполните:

```sh
cd examples/counter
acton init --stdlib-only
acton fmt --check
acton build
acton wrapper Counter --output-dir wrappers
acton check
acton test
```

Или вернитесь в корень проекта и запустите `npm test`: Python-регрессия выполнит эти же локальные проверки примера. Инициализация Acton устанавливает стандартную библиотеку; транзакции в сеть не отправляются.

`wrappers/Counter.gen.tolk` — сгенерированная обёртка, которую можно пересоздать командой `acton wrapper Counter --output-dir wrappers`.

## Границы примера

Здесь намеренно нет скриптов деплоя, кошельков, сетевых адресов, `.env` или команд отправки транзакций. Пример предназначен для изучения языка и эмуляционных тестов, а не для развёртывания или хранения реальных средств. Не копируйте его в production-контракт без отдельного анализа угроз и независимой проверки.

## Структура

- `contracts/Counter.tolk` — обработка внутренних сообщений и getters.
- `contracts/types.tolk` — storage, сообщения и коды ошибок.
- `tests/counter.test.tolk` — эмуляционные тесты Acton.
- `wrappers/Counter.gen.tolk` — ABI-обёртка, сгенерированная Acton.

Шаблон и синтаксис можно сверить с [официальной документацией Acton](https://ton-blockchain.github.io/acton/docs/installation) и [разделом документации по тестам](https://ton-blockchain.github.io/acton/docs/commands/test).
