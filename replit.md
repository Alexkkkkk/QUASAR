# QUASAR

## Обзор проекта

QUASAR — Jetton для блокчейна TON, реализованный на Tact. Репозиторий содержит:

- смарт-контракты в `contracts/`
- скрипт деплоя в `scripts/deploy.ts`
- статический сайт в `website/`
- скомпилированные артефакты Tact в `build/`

## Запуск и проверка

```bash
npm install
npm run build
npm run lint
npm test
```

Предпросмотр сайта запускается workflow `QUASAR Website` и доступен через Replit Preview.

## Деплой в TON

Перед деплоем нужно создать `.env` на основе `.env.example` и заполнить параметры сети, API и кошелька. Скрипт деплоя отправляет транзакции и не должен запускаться с непроверенными параметрами или в mainnet без аудита.
